# AI features

The Personal AI Vicinae extension offers **Summarize**, **Extract action items**,
**Explain**, **Translate**, and **Rewrite**. Open the list with `Mod+A`, choose
clipboard or entered text, and enter any task-specific instruction. Results stay
in Vicinae for copying or pasting.

GNOME Files also has **Sort files** in a folder's background menu. The local AI
model groups up to 80 top-level files into topic folders from filename metadata.
Review the proposed moves in a checklist before applying them.

The Vicinae workflows use the private local route through the privacy router.
The file sorter calls the local model endpoint directly.
The Bun registry accepts only those five manual workflows; no time, path, or
notification events are configured.

Previous data under the persisted `~/AI` directory is left intact.
